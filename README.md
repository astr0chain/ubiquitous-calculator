# Ubiquitous Calculator 🧮✨
A dead-simple, responsive calculator built with **pure HTML + CSS + JavaScript**—no frameworks, no build step.

---


## Live Demo
👉 https://astr0chain.github.io/ubiquitous-calculator

(Works great on mobile too—tap the 🌙 icon for dark mode.)

---

## Features
* Basic arithmetic: `+ − × ÷`
* Clear (`C`) and **keyboard** input support
* Light / dark toggle
* Zero external libraries → instant load
